# rawfile

`npm run harmony:sync` (repo root) copies `dist/` here, next to this note.

The copied `index.html` and assets are a local build output. They are gitignored. They are not a HAP, and they are not proof that HarmonyOS NEXT can run the camera or the ear-capture flow.

Run the sync before opening the project in DevEco, or the Web component has no `index.html` to load.
