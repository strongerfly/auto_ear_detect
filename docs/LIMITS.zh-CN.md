# 上限与卡点 / Limits

On-device **face pose + ear-ROI quality peak search**。不是医院外耳道成像，也不是假定人人同一个绝对 yaw。我们在可跟踪的侧转范围内，选结构最清楚、且稳住的那一帧。

Capture mode: `qualityPeakYaw`（`src/config/pose-config.json`）。READY **不要求** yaw ∈ [70, 90]。个人峰值在 **~45°** 也可以拍。

英文对照：[LIMITS.md](./LIMITS.md)。交互清单：[ear-guide-interaction-gaps.md](./ear-guide-interaction-gaps.md)。

## 一句话边界

用 MediaPipe 头部位姿做**方向**，用耳区 ROI 的清晰度/结构分判断「这只耳朵对这个人够不够正」。在可跟踪的侧转范围里搜峰值，而不是卡死 70–90°。

---

## 卡点 / Blockers

下面是**仍然不能完整解决**的事。每条都写了试过什么、现在落到哪一步——「做不到」不是跳过。

| 仍卡着 | 试过 | 已落地的半截路径 |
|--------|------|------------------|
| **没有专用耳分割 / 检测模型** | 用 MediaPipe 脸网格耳点当 3D 耳 | **没接。** 侧脸上这些点不稳，READY 用头部位姿指方向 + **脸网格推出来的耳区裁剪**，并不认识「这是耳朵」。 |
| **MediaPipe 耳 landmark 侧脸不可靠** | 同上 | 有脸时裁 ROI；裁到头发/背景时，分数仍可能在那里出峰。 |
| **笔记本摄像头 FOV / 距离** | 搜索窗放到 100°、READY 卡 70–90 | 搜索是 **\|yaw\| 35–90**（软偏好 40–80）。**不**把用户按进笔记本特有的 70–90 姿势。窗外的真峰值采不到。 |
| **转头运动模糊** | One-Euro 平滑；yaw 跳变时 SLOW_DOWN；READY 要约 12 帧稳住 | 糊帧不太容易锁峰，但慢慢糊着停住仍可能得分。没有光流 / 陀螺仪融合。 |
| **头发遮挡** | 靠近已锁峰值且 Laplacian/边缘低时 CLEAR_HAIR；一直没峰则 FAIL_TIMEOUT | 看不见头发下面。反光/头发纹理可能赢过真耳廓（假峰）。 |
| **背景纹理假峰** | 加权分（0.45 Laplacian + 0.35 边缘 + 0.20 侧脸）；中心暗斑惩罚；近同分偏 **更小 \|yaw\|** | 没有分割时，窗帘/镜框进 ROI 也能赢。偏好带未中只 **−0.1**，绝不因此拒绝 45°。 |
| **大 yaw（~90°）跟踪丢失** | `FAIL_TRACKING`；**bestYaw 保留**；没脸时暂停打分 | 没有 last-good 欧拉冻结成 3D 耳。过 ~90° landmarker 经常挂。 |
| **Laplacian 绑死设备** | 配置里 raw min 80 / good 120 | 换电脑会漂。没有开机一次的模糊标定。 |
| **解剖「耳正面法向」≠ 我们的分数** | 用个人 `bestYaw` 替换固定 70–90 READY | 最清楚的稳定耳廓 ≠ 外耳道轴。不是 otoscope。 |

## 当前上限 / Ceiling

浏览器里**今天能稳定做到的**（真机摄像头或姿态模拟器）：

- 每一侧在转头过程里学 **质量峰值 yaw**。搜索 \|yaw\| **35–90°**，软偏好 **40–80°**。**~45°** 峰值可以 READY。
- 分数 = **0.45 Laplacian + 0.35 边缘 + 0.20 侧脸内容**。`bestYaw` 是跑分最高时的 yaw；近同分走 `smallerAbsYaw`。
- **READY**（同时满足）：脸在框里、距离 OK；这一侧已锁 `bestYaw`；当前 yaw 在最佳 **±5°**（`bandDegAroundBest` 进入带，**不是** 8）。`exitBandDeg` **8°** 只是滞后，防止 READY 闪烁，不是更宽的进入门。pitch/roll 在限内；约 **12** 帧稳定；分数 ≥ 峰值 **92%**；亮度 60–200。**没有** yaw ∈ [70, 90]。**没有**「请确认耳朵正了」。
- 还在学习（未锁峰）：**只有扫掠引导**——60° 先验不会触发「再转一点点 / 往回一点 / 保持不动」。
- 锁峰后转过头：朝**个人**峰值 TURN_BACK；窗口外沿「到头了，往回一点」。
- 脸跟丢：暂停打分，**保留** `bestYaw`，回来再往峰值靠。
- 自动快门可选（**默认关**）。READY 之后用 **3 帧缓冲选最高分**（`ready.pickBurstBy: "score"`）。手动拍在缓冲热了时同样选最高分。
- 平时界面**不显示**绝对目标角度（调试折叠里才有）。
- 文案在 `src/i18n/` 中英切换。「重新学习此侧」确认后清峰值。

## 短板 / Shortfalls

对比理想状态「总能找到真正的耳正面」还差什么：

- 分数是**猜的 ROI 里清不清晰**，不是几何耳法向，也不是医生说的耳廓正面。
- 头发、眼镜、耳饰、背景纹理仍会出**假峰**；恢复靠重新学习，不是检测器。
- 大侧面跟丢时，`bestYaw` 可能停在窗口**内侧**（约 35–45°），即使更外头还有更好姿势。
- 笔记本 vs 手机 FOV：同一人可能笔记本 45°、手机 70°；我们会学，但不能承诺度数可移植。
- Burst 只是 **3 帧未对齐的整帧、取最高分**——不是对齐超分，也不是 JPEG 堆叠融合。
- `minSweepCoverageRatio`（0.6）写在配置里，**故意不当 READY 硬门**（否则 45° 停住的清晰耳会被逼去转满窗）。
- 下次会话的 `clampOffsetDeg` / 收窄 10° **没启用**（旧峰值 80° 会把新的 45° 拒掉）。
- Face Landmarker 在主线程，可能卡一下；还没有 Worker。
- CI 没有真机摄像头 E2E（只有单测 + 模拟器）。

## 后续优化 / Next optimizations

按产品顺序，不是愿望清单：

1. **耳检测 / 轻量分割**——把头发和背景从分数里拿掉。
2. **学出来的 quality 头**（哪怕很小的端上分类器），用按角度标注的耳 ROI 替代现在的 Laplacian 权重。
3. **按设备标定模糊阈值**——一次平面/手掌标定，让 min/good Laplacian 跟摄像头走，而不是永远 80/120。
4. **更强的多帧 burst 融合**——保留 N 帧就绪图，对齐后再选或融合；今天的 3 帧选最高分只是第一步。
5. **跟丢时冻结 last-good 位姿**；可选 IMU / 更慢的 yaw 先验。
6. **推理进 Worker**，避免 UI 线程卡顿。
7. 只有产品真的要拍外耳道时，才上单独的 **meatus** ROI/模型（需要临床定义和知情同意）。

---

## 优化条件 / Conditions

没有这些条件，上面的优化只是口号：

- **按角度标注的耳数据集**（左/右、含 ~45° 和 ~80° 的 yaw 箱、头发开/关、多台摄像头）。没有它，学出来的 quality 头会过拟合笔记本反光。
- **端上模型体积 + 延迟预算**（WASM / 轻量 GPU，按我们真实交付的笔记本 SKU 算 ms/帧）。
- **按设备标定流程**（模糊 + FOV），如果想让 Laplacian 数字可移植。
- 任何耳分割模型都要有 **侧脸标注集**，并且在 landmarker 已经不稳的 ~80–90° 仍站得住。
- 若以后要做**弱**的下次搜索收窄，必须是同一人同一设备——而且不能拒绝新的 45° 峰值。
- 若范围包含外耳道成像：临床定义 + 知情同意。

## 试过、只做到一半的

- **固定 70–90° READY：** 已弃用。位姿只做转向提示；READY 看个人 bestYaw。
- **问用户「你是不是 45° 那种」：** 不做。转头过程里自动记峰值。
- **专用耳 landmark / 3D 耳：** 未接。MediaPipe 脸部耳点在侧脸上不可靠，所以用头部位姿 + ROI 质量。触发条件：有稳定侧脸耳分割模型且延迟可接受。
- **扫过窗口 60% 才允许 READY：** 配了 `minSweepCoverageRatio`，**故意不作为硬门**。否则 45° 附近停住的清晰耳会被逼去转满窗。只在文档里当「假峰风险」说明。
- **45s 超时失败文案：** `FAIL_TIMEOUT` 只在**一直没学到峰值且几乎停住**时出现；有 45° 峰值时仍可 READY，不当主路径催促。
- **外耳道暗斑惩罚：** 用 ROI 中心亮度做了很弱的启发；没有分割时分不清 meatus 和头发阴影。
- **Burst 按分数选帧：** 最近 **3 帧 READY 图**里留分数最高的一张。不是对齐融合。

## 不做（Won't do）

- 固定 70–90 作为 READY 硬门
- 主路径等人按「耳朵已经正了」
- 在没有上表触发条件时上专用耳 landmark / 3D 耳模型
- 在平时界面显示绝对目标 yaw

## 当前 READY（实现）

1. 脸在框里、距离还行  
2. 这一侧已经有过 **bestYaw**（搜索窗内质量分最高的 yaw）  
3. 当前 yaw 在 bestYaw **±5°**（已经就绪后退出 **8°**），pitch/roll 在 ready 限内  
4. 连续约 12 帧角度稳定  
5. 耳区分数 ≥ 该侧峰值的 **92%**，亮度 60–200  
6. 不要求 yaw ∈ [70, 90]；不要求用户确认  

引导：一条短提示，中英可切换。远了只说转向（慢慢找最清楚的角度 / 再转一点点 / 往回一点），靠近了才提头发、光线、摆头。READY 切换更快，避免提示像清单一样刷。
