## 平台事实（做不到的）
- Grok Bot 的机器人、群聊、会话记录绑定 **当前登录的 Cursor 账号**。
- 切换账号不会自动带走侧边栏团队；也没有「一键把团队迁移到另一账号并保留全部聊天」的官方能力。
- On-demand / Cloud Agent 额度也绑定账号，所以「A 号有团队、B 号有额度」会打架。

## 目标做法（推荐）
**选定一个「工作账号」长期不动**（建议：有 On-demand 且能访问 strongerfly/auto_ear_detect 的那个）。
- 日常编排、工程/调研/测试派单、Cloud Agent，都只在这个账号下的 Grok Bot 做。
- 另一个账号只作备用，不要来回切。

## 若必须换到额度账号（一次性重建）
1. 在旧账号：把各角色导出为 **Public 模板**（总管 / 工程 / 调研 / 发布巡检 / 文档 / 测试 / 交互）。
2. 在新账号：按模板 Import，建同名机器人；重建群「工程协作」「产品体验」。
3. 把本交接文件里的 **未完成进度板** 贴进新总管第一条消息，说「按交接续做」。
4. 仓库与本机路径不变，**禁止重写产品**。
