# 安全包络 — 工位式外耳采集 PoC

**视觉不是唯一安全依据。** 丢跟踪、ROI 分数或人脸在场绝不能作为防止接触的唯一层。实机前必须具备协作臂力/力矩限制、速度限制、工作空间约束与硬急停。

## 占位参数（产品阈值未定）

| 参数 | 占位 | 说明 |
|------|------|------|
| TCP 线速度（近脸接近） | ≤ **50 mm/s** | 近脸区 |
| TCP 线速度（工位转移） | ≤ **200 mm/s** | 远离头部 |
| 腕部角速度 | ≤ **15 °/s** | 近脸 |
| 最小人机距离 | ≥ **80 mm** | 深度+模型；失效则保守 |
| 近脸禁入球半径 | 距估计耳廓 **120 mm** | 软虚拟墙 |
| 丢跟踪超时 | **200 ms** | 触发回撤 |

## 行为规则

1. 先同意再运动  
2. 丢跟踪立即回撤  
3. 不追逐离座对象  
4. 近脸禁用高速  
5. 高分数≠允许更近  
6. 仅成人工位，无儿童/无家庭移动底盘  

## 硬急停检查清单

见英文版勾选表（物理急停、软件停、协作模式、围栏、丢跟踪演练、死手开关、取消与复位+重新同意）。

SIM 仅有同意布尔与假人脸标志，**未实现**急停/力限/深度禁入。
